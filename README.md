# RideFlow

> Event-Driven Ride Booking & Driver Matching Platform

RideFlow is a backend microservices project inspired by modern ride-hailing platforms like Uber and Ola.

The project is being built using Spring Boot, Redis Geospatial, Apache Kafka, MySQL, and Docker while following an event-driven microservices architecture.

---

## 🚀 Tech Stack

- Java 17
- Spring Boot
- Spring Data Redis
- Spring Data JPA
- Apache Kafka
- Redis (Geospatial)
- MySQL
- Docker
- Maven
- REST APIs
